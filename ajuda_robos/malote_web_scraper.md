# Consulta ao Malote Web

## Componente interno

Este arquivo documenta um componente interno utilizado pelo robô Rateio de Malote.

A consulta ao Malote Web não aparece como uma automação independente no Hub Central e não deve ser executada diretamente pelo usuário.

## Função do componente

O componente consulta as informações necessárias no sistema Malote Web dos Correios e fornece os dados utilizados durante a geração do rateio.

## Configuração necessária

Para que a consulta funcione, a senha do Malote Web deve estar preenchida na seção Configurações do Hub.
